# Projetos do 1º Período – Ciência da Computação (PUC-Rio)

Este repositório reúne trabalhos desenvolvidos durante o primeiro período do curso de Ciência da Computação na PUC-Rio. Os projetos foram implementados em Python e têm como foco o desenvolvimento de lógica de programação, interação com o usuário e introdução a bibliotecas gráficas como Turtle e PyGame.

---

## 1. Coleção de Jogos em Python

O objetivo original deste trabalho era desenvolver dois jogos dentre algumas opções propostas. No entanto, foram implementados todos os quatro jogos, além de um menu inicial para navegação entre eles.

### Jogos incluídos

#### Jogo da Forca

Requisitos implementados:
- Condição de vitória ao acertar a palavra completa;
- Condição de derrota ao perder todas as vidas (6 no total);
- Geração de palavra aleatória a partir de uma lista temática;
- Validação de entrada (somente letras);
- Possibilidade de chute da palavra completa;
- Reinicialização do jogo.

Funcionalidade extra:
- Versão com interface gráfica utilizando PyGame.

---

#### Pedra, Papel e Tesoura

Requisitos implementados:
- Regras clássicas (Pedra > Tesoura > Papel > Pedra);
- Escolha do jogador;
- Jogada aleatória do computador;
- Sistema de pontuação;
- Reinicialização do jogo.

Funcionalidade extra:
- Interface gráfica com imagens utilizando PyGame.

---

#### Calculadora

Requisitos implementados:
- Operações básicas entre dois operandos;
- Armazenamento do resultado da última operação;
- Encadeamento de operações (ex: 5 × 3 seguido de + 4 resulta em 19);
- Restrição a operações com dois operandos por vez.

Funcionalidade extra:
- Interface gráfica inspirada em calculadoras utilizando PyGame.

---

#### Jogo de Adivinhação

Requisitos implementados:
- Geração de número aleatório entre 1 e 1023;
- Feedback por tentativa:
  - -1: número gerado é menor;
  - 1: número gerado é maior;
  - 0: número correto;
- Contagem de tentativas;
- Alternância de papéis entre usuário e computador.

Funcionalidade extra:
- Interface gráfica com indicadores visuais utilizando PyGame.

---

## 2. Gráficos de Funções com Turtle

Projeto voltado para a visualização de funções matemáticas utilizando Python e a biblioteca Turtle.

Funções implementadas:
- y = √x  
- y = 1/x  
- y = 2^x  
- y = 5 - x²  
- y = x² - 5x + 6  
- y = x³ - x² - x + 1  

Este projeto explora a representação gráfica de funções e reforça conceitos matemáticos fundamentais.

---

## 3. Desenho de Bandeiras com Turtle

Projeto de construção programática de bandeiras de diferentes países utilizando a biblioteca Turtle, com foco em proporção, geometria e composição visual.

Bandeiras implementadas:

Fácil:
- Japão  
- Suíça  

Médio:
- Emirados Árabes Unidos  
- Bahamas  
- Jordânia  
- Laos  
- Sudão  
- Níger  

Difícil:
- São Vicente e Granadinas  
- Estados Unidos  

Muito difícil:
- Camboja  

Observação:
A bandeira do Camboja apresentou maior complexidade de implementação. Apesar de não ser totalmente fiel, o resultado final foi satisfatório.
